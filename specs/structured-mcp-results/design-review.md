Status: draft self-validation complete; critic/peer reviews pending. Internal mode only; no external-model disclosure.

## Explanation self-validation (explain-like)

Beginner: Transit keeps the saved answer exactly as evidence, then puts readable fields in a separate structured box. Extra labels cannot overwrite the saved answer. A retry asks for the same saved write, not a fresh write. The server first checks that clients speak the approved modern protocol; it cannot switch production until actual clients prove they can use it. The load-bearing assumptions are explicit: the original evidence is authoritative, navigation is unavailable, and installed modern code is not proof of active support.

Intermediate: Each provider declares generated JSON, retained JSON or plain text. A lossless immutable document preserves source tokens and optional error presence; a pure adapter adds deterministic links/categories. Captured pages retain this tool-level evidence and metadata without an RPC ID. Whole modern bytes are assembled inside T63's admitted worker before its publication domain selects response and retained handles together. Single/batch writes preencode a correlated uncertainty fallback before effects; response failures leave saved receipts unchanged.

Expert: Acceptance-state authority remains T2380 validation/transaction; JSON syntactic validity alone does not establish commitment. Unsupported/malformed evidence is a presentation-level unestablished status with no fabricated no-effect classification. Typed value boundaries prevent live models/unchecked Any crossing actors; complete validated raw-fragment insertion avoids numeric coercion. Publication and response selection have no encoding under the lock, and cancellation does not release physical permits early. Modern per-request metadata and HTTP mirrored-header checks precede semantic dispatch; subscription correlation is request-scoped, not session state.

Gaps resolved by explanation: source origin must be declared to distinguish old prose errors from corrupt receipt JSON; source syntactic validity is distinct from established outcome evidence; fallback preparation failure must stop before effects. No unstated activation assumption remains. Production-volume encoding/capacity is the sole measurement risk, with explicit failure/verification paths in design.
