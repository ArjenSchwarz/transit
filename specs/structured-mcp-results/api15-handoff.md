## Consumer interfaces

All types are project-internal Swift values. Consume the delivered declarations directly; do not define a parallel envelope, receipt adapter or acceptance engine.

- `MCPResultAdapter.source(text:isError:origin:evidence:checkpoint:) throws -> MCPResultSource` owns original text, optional error flag and lossless JSON. Declare `.retainedJSON` for historical receipts, `.generatedJSON` for newly generated logical batch JSON, and `.plainText` for actual textual evidence. Malformed/depth-limited historical input retains raw text as `.unreadable`/unestablished; malformed generated input throws. Checkpoint failures propagate.
- `MCPResultAdapter.present(_:context:checkpoint:) throws -> MCPResultPresentation` derives supplemental classification, recovery and source-backed link pointers without changing the source. Context carries tool, typed failure, mutation recovery and explicit entity positions. Navigation links remain unavailable with `navigation_not_supported`; this does not implement T572 navigation.
- `MCPResultEncoder.encode(source:presentation:id:metadata:checkpoint:) throws -> Data` returns complete modern response bytes. `freeze(source:presentation:metadata:checkpoint:)` creates an ID-independent `MCPResultToolFragment`; `encode(fragment:id:checkpoint:)` applies a new request ID.
- `MCPResultEncoder.prepareMutationFallback(id:source:context:metadata:checkpoint:) throws -> Data` prepares complete correlated bytes before effects. The provider supplies its compact logical failure source. Batch fallback presentation omits itemId, links and diagnostic expansion while retaining original index/operation/tool/key/target UUID recovery identities. No acceptance or durable key is invented.
- `MCPResultProviderSelection.mutation(id:context:metadata:fallbackSource:prepareFallback:encodeOutcome:shouldDeliver:dispatch:) async throws -> MCPResultResponseSelection` prepares before dispatch, dispatches once and returns `.normal(Data)`, `.reconciliation(Data)` or `.suppressed`. Post-dispatch provider/adapter/encoding failure selects already prepared bytes without a second encoder call. Preparation failure dispatches nothing; cancellation suppresses delivery without reinterpreting effects. Dispatch returns immutable `MCPResultProviderOutcome(source:context:)`; original recovery identity must match.
- `MCPResultProviderAdapters.outcome(result:context:origin:checkpoint:)` bridges exactly one existing text content block using optional non-wire `MCPResultProviderEvidence`. `metadata(result:frozenReadBytes:checkpoint:)` preserves frozen read metadata bytes in their existing namespace. `MCPToolResult.providerEvidence` is excluded from CodingKeys and persisted outcomes.
- `MCPResultSchemas.descriptor(tool:description:)` supplies the common immutable output descriptor. Retained `MCPToolDefinitions.modernTools(includingMaintenance:)` maps existing definitions through that descriptor once. Real `mutate_tasks` registration remains T2384-owned and requires coordinated owner integration.
